# Kampüs Etkinlik Portalı - Sprint 1

Bu proje, üniversite kampüsündeki etkinlikleri listelemek, detaylarını görüntülemek ve yeni etkinlik eklemek için geliştirilmiş HTML tabanlı bir web projesidir.

## 🚀 Canlı Site (Vercel)
Etkin projenin canlı adresi: [https://kampus-etkinlik-sprint1.vercel.app](https://kampus-etkinlik-sprint1.vercel.app)

## 📁 Sayfa Yapısı
* `index.html`: Ana sayfa, genel bilgilendirme ve öne çıkan etkinlikler.
* `etkinlikler.html`: Tüm etkinliklerin listesi ve ayın programı özeti.
* `etkinlik-detay.html`: Seçilen etkinliğin afiş ve detaylı künye bilgileri.
* `etkinlik-ekle.html`: Yeni etkinlik ekleme formu.
* `etkinlik-guncelle.html`: Etkinlik bilgilerini düzenleme formu.

## ⚙️ Özellikler
* Sadece HTML5 semantik etiketleri kullanılmıştır (`header`, `nav`, `main`, `footer`, `article`, `figure`, `dl`).
* Tasarımda hiç CSS ve JavaScript **kullanılmamıştır**.
* Form alanlarında gerekli yönlendirmeler için `required` niteliği eklenmiştir.
